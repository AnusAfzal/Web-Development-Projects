# My Web Development Projects

This repository contains my Frontend and Backend projects built while learning and practicing web development.

I have worked on multiple projects using different technologies including HTML, CSS, JavaScript, Node.js, Express, and EJS. These projects helped me understand both client-side and server-side development.

## Frontend Projects

The frontend section includes UI-based projects built using:

- HTML
- CSS
- JavaScript

These projects focus on layout design, responsiveness, and user interaction.

### Examples:
- Amazon Repica
- Border Radius
- Sidebar
- Simon's Game
- Spotify Clone
- Typing Speed Test
- Weather app 
- Binary To Decimal Converter


## Backend Projects

The backend section includes server-side projects built using:

- Node.js
- Express.js
- EJS (templating engine)
- RESTful APIs

These projects focus on routing, CRUD operations, and dynamic data rendering.

### Examples:
- Blog Application (Full CRUD)
  - Create blog posts
  - Edit posts
  - Delete posts
  - View all posts
  - View single post

## Features Learned

- RESTful API structure
- Dynamic routing
- Middleware usage
- Form handling
- Method override (PATCH & DELETE)
- Server-side rendering with EJS

## Purpose

The goal of these projects is to strengthen my understanding of full-stack web development and build a strong foundation for real-world applications.
