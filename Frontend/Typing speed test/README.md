# Typing Speed Test

A typing speed testing application with timer functionality.

## Description
User starts typing in the input box and timer starts automatically. After completion, results are shown and a restart button appears to reset everything.

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- Auto-start timer on typing
- Accuracy and speed tracking
- Restart functionality
- Full reset system

## Purpose
To practice DOM events, timers, and state reset logic in JavaScript.
