# Border Radius Generator

A small tool to dynamically change CSS border-radius values.

## Description
This project allows users to input values for each corner of a box. On button click, the border-radius updates accordingly using JavaScript.

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- 4 input fields for each corner
- Real-time border-radius update
- Interactive UI

## Purpose
To understand DOM manipulation and CSS property control using JavaScript.
