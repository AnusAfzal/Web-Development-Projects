# Weather App

A weather forecasting app using a public API.

## Description
User enters a city name and clicks a button. The app fetches live weather data and displays it in a dynamically created UI card.

## Tech Stack
- HTML
- CSS
- JavaScript
- Weather API

## Features
- City search functionality
- API integration
- Dynamic DOM element creation
- Live weather data display

## Purpose
To practice API handling, async JavaScript, and dynamic UI rendering.
