# Frontend Projects Collection

This repository contains multiple frontend practice projects built using HTML, CSS, and JavaScript.
Each project is organized in its own folder and focuses on building core UI and logic skills through hands-on practice.

# Tech Stack

HTML5
CSS3
JavaScript (Vanilla)

# Projects Included

1. Amazon Replica

A UI clone of Amazon homepage focusing on layout, product cards, and responsive design.

2. Binary to Decimal Converter (bin2dc)

Converts binary numbers into decimal using JavaScript logic.

3. Border Radius Generator

A tool to visually adjust and generate CSS border-radius values in real time.

4. Sidebar UI

A responsive sidebar navigation menu with toggle functionality.

5. Simon’s Game

Memory-based game using sequence matching and DOM interaction.

6. Spotify Clone

A frontend clone of Spotify UI focusing on layout and modern design structure.

7. Weather App

Fetches live weather data using API and displays temperature, condition, and location info.
