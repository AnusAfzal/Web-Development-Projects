# Amazon Replica

This is a frontend clone of the Amazon homepage built using HTML and vanilla CSS.

## Description
This project replicates the basic UI of Amazon including navigation bar, product sections, and layout structure. The focus is on HTML structure and CSS styling.

## Tech Stack
- HTML
- CSS (Vanilla)

## Features
- Responsive layout design
- Product grid structure
- Navigation bar similar to Amazon UI
- Static UI clone (no backend functionality)

## Purpose
Built for practicing frontend layout design and improving CSS skills.
